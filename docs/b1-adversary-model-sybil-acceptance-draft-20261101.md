# B-1 第2回むせ監査後：公開判断の保留条件と攻撃者モデル v0.1
2026-11-01 / 設計レビュー用。本番適用、正式同意、一般公開は禁止。

## 1. プライバシー受入条件（暫定・審査待ち）
単一セルの丸め幅だけでは可否を決めない。攻撃者が観測できるすべての公開値（年別国別セル、他の公開統計、過去保存値、本人の寄与、外部で既知の走行距離）を組み合わせ、各個人の寄与の可行区間を最適化する。
- いずれかの攻撃モデルで個人の距離が一意復元される、または狭い幅で推定されるなら「不合格/非公開」。『狭い幅』の数値基準は独立監査と実分布確認後に決め、決定前は公開不可。
- 推定可能幅はプライバシーリスクの一指標にすぎない。識別可能性、存在推定、外部プロフィール情報、過去公開版、複数アカウントの影響も評価。
- 1国×年の数値が単独で安全でも、既存公開総計との引き算で危険なら非公開。
- 評価を実施できない攻撃モデルがある場合、公開許可にはしない。閾値は確定せず、公開価値より安全性を優先。

## 2. Sybil（複数アカウント）に関する設計判断
- **登録アカウント数をそのまま独立参加人数とみなさない。** 外部連携の存在だけでも同一人物が複数IDを操作するリスクは残る。
- 閾値計算に使う「独立した実在参加者数」は現段階では検証不能。したがって匿名性の公開判定は自動で許可しない。
- 今後の候補: アカウント登録からの経過日数、出所の異なる活動の整合性、重複活動・重複外部連携IDを非公開側で検知する。どれも本人性の証明ではなく、誤判定・不当排除・個人情報保護の別審査が必要。
- 収集する属性は最小限。追加の本人確認書類、公開プロフィール、実名提出を初期要件としない。偽アカウント対策が保証できなければ数値公開は見送る。

## 3. 連立推定テストの仕様
次の各組合せについて合成データで数値制約を作り、個人寄与の上下限・幅、攻撃成功数を測る。
1. 国×年セルと前年度の同一ランナー
2. 国×年セルと現在サイトの総ラン距離・国別走行距離チップ
3. 地域間・国間で同一ランナーの活動が重なるケース
4. 過去の公開スナップショットの保存と撤回前後
5. 参加者自身が自己の寄与を知り、他人の残差を推定するケース
6. 攻撃者が上位寄与者を外部から知るケース
公開総計が国×年の対象母集団と一致しない場合、安易に等式を立てず、合成データの母集団の共通部分と非共通部分を明示する。過剰に安全と判定しない。

## 4. 実データ分布の検証手順（未承認）
実際の人数、寄与支配、国×年分布を評価する必要がある。取得前にAtsuo承認、読み取り専用アクセス、目的の限定、短期保持、実ユーザーデータをGitHubやログに残さない方法、むせ監査を確定する。
承認までは合成データのみ使用。少数セルの機密数値をチャット・リポジトリに転載しない。

## 5. 公開前の残ゲート
- 連立推定エンジンの実装と最悪推定区間幅の評価
- 推定幅の受入基準・最低人数・支配率・丸め幅の独立監査とAtsuo承認
- Sybil対策のリスク受容判断
- 実分布評価（事前承認）
- 同意撤回→世代失効→配信停止の隔離DB通し試験、競合試験
- API実装後の HTTP/CDN/ブラウザ/SW キャッシュ検査
