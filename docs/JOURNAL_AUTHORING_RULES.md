# Rings Journal 原稿作成・一括入力の正式ルール

制定：2026-10-28。Runner's Rings のJournal原稿をチャッピーが作るときに、毎回確認する正本。

## 1. 必須7項目（ラベルの綴り・順番を固定）

【日本語タイトル】
日本語タイトル

【English title】
English title

【日本語概要】
日本語概要

【English summary】
English summary

【日本語本文】
日本語本文

【English body】
English body

【カテゴリ】
開発日記

## 2. 納品形式

- **必ず上記7ラベルを含む、原稿全文を1つのコピー可能なブロック**で納品する。
- 7項目を別々のコピー枠に分けない。タイトルやカテゴリの一部を枠外に置かない。
- 各ラベルは管理画面のパーサーに合わせて **【日本語タイトル】、【English title】、【日本語概要】、【English summary】、【日本語本文】、【English body】、【カテゴリ】** と表記する。Markdownの `**...` などの装飾をラベル自体に付けない。
- 日本語・英語ともに本文を省略しない。事実確認を要する情報は確認後に書く。プライバシーに配慮する。
- 依頼が記事本文の改稿なら、変更後の7項目すべてを再提示し、一括貼り付け可能にする。

## 3. 掲載操作

管理画面 `journal-admin.html` の **「記事をまとめて入力」** に全文を1回貼り付け、**「各項目に反映」** を押す。各欄に振り分けられる。**この操作は公開・保存を自動実行しない**ので、内容確認後に別途保存・公開する。

## 4. カテゴリ

管理画面の選択肢（2026-10-28実コード確認）：
- 開発日記
- 世界のランナー
- **Rings People（インタビュー）**
- GPSアート
- 今週の発見
- その他

従来の「5分類」に加え、現行管理画面には **Rings People** がある。ユーザーが特定カテゴリを指定した場合はそれを優先し、未指定なら記事内容に応じて選ぶ。

## 5. 再確認と責任

新しいスレッドでも記事作成前にこのファイルと `journal-admin.html` の現行仕様を照合する。未確認のまま「大丈夫」と断言しない。管理画面の仕様変更時はこのルールを更新する。
