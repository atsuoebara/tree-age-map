# B-1 Sybil and numeric-publication decision record — 2026-11-01

## Final decision by Atsuo: option C
Do **not** include public country-by-year anonymous numeric totals in the initial release. Keep the already approved private, owner-only region rings experience. Do not start collecting formal aggregation consent; do not activate public delivery endpoints or numerical pages. No production DB/API changes are authorized by this record.

## Basis
Independent Muse audit #14: synthetic policy/CI tests passed but independent-person assurance remains unavailable. Account counts, external provider links and activity fingerprints do not prove unique humans. Evidence 1 demonstrates reconstruction risk when public aggregate values combine with other knowledge. Public numeric utility does not justify proceeding without assurance.

## Individual control disposition
1. External provider-ID duplication checks: **do not deploy for public eligibility now**. They may be useful signals but cannot prove unique persons; provider terms, privacy and false-positive issues require separate audit.
2. Overlapping activity fingerprints: **do not deploy for public eligibility now**. Legitimate synchronized imports, migrated accounts and shared environments can cause false positives; storing route-like fingerprints raises data-minimization issues.
3. Account maturity: **do not use as a publication threshold now**. Old accounts can still be controlled by one person; newer genuine accounts should not be unfairly excluded.

## False-positive handling
Do not automatically ban, penalize or subtract contributors from any independent-person count solely because of a duplicate provider ID, matching activity, or young account. No person-specific Sybil label is exposed. Additional investigation requires separately approved procedures.

## Re-evaluation triggers
Any proposal to publish country-year numeric totals; provider or account-linking changes; new consent/withdrawal implementation; substantial new risk-control capabilities; major changes to available public statistics. Re-evaluation requires separate threat assessment, data-minimization review, independent Muse audit and **explicit Atsuo approval**, not an automatic transition.

## Scope / release status
This closes the **decision** to defer public numeric publication, not Sybil-proof verification. Formal consent OFF; anonymous country-year public numeric publication OFF; production Supabase unchanged; no new public API or suppression-display implementation authorized. Existing non-B-1 site features are not modified.
