# 今を知ろう：既存カレンダー個別ランの受け渡し試作（2026-11-13）

## 背景と確定決定
本人が選んだ**個別のガチラン**に「今を知ろう」を提供する。内部「1km解析」は別名の新機能ではない。カレンダーの日付・距離、同日複数本の個別選択、地図遷移、配色を変えない。診断可能期間は走行開始から8日（691200秒）、境界は有効、超過失効、過去に遡及せず、遅延取り込みで復活なし。

2026-11-13の停止時間の最新決定は、信号・トイレだけで一律除外しない、停止を含む時計経過時間で解析、自動ポーズ等があると正しく分析できない可能性の注意、補正・数値捏造なし。11/12以前の停止一律排除候補を採用しない。

## 変更と安全境界
- `src/ima-wo-shirou-calendar-selection-review.mjs`：既存の保存済みラン1件を本人選択として扱う**隔離アダプター**。該当個別記録の `id`, `user_id`, `started_at`, `deleted_at` を読み取り検証。カレンダー日付 `activity_date` を期限判定に転用しない。
- `started_at` はISO日時・タイムゾーン表記必須。異常入力を推測で修正しない。
- PR #101の期限ゲートに依存し、呼び出し側から `maxAgeSeconds: 691200` を明示する。
- **期限内でも `analysisAllowed:false`**：FIT実データの取得、品質認定、本番診断は一切行わない。
- `index.html`, `sw.js`, カレンダー本体、DB、認証、通信、永続化、デプロイ変更なし。追加費用0円。
