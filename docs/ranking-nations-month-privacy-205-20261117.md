# PR #206 / Issue #205 — NATIONS月間 人数閾値方式のプライバシー検討
2026-11-17 / **設計・合成攻撃検証のみ / 公開承認ではない**

## 結論
Atsuo指示：「人数閾値方式を検討、プライバシー監査優先」。
**閾値のみでの公開は不可。人数値は未決定。** NATIONS月間は公開HOLDとする。
2026-11-01 `docs/b1-sybil-option-c-final-decision-20261101.md` で採択済みの「国×年の数値も初期リリース非公開」より狭い「国×月」を自動的に許可してはならない。
既存の年間NATIONSはすでに提供される別機能であり、このPRで変更しない。既存公開値との突き合わせは攻撃面として検証する。

## 攻撃者視点の仮定と攻撃
`node scripts/test-ranking-nations-privacy-205.cjs`：合成値のみ、6項目PASS。これは **漏えいの反例** を再現するテストで、安全性の証明ではない。
- 1人の国は国合計 = 個人の月間距離。
- 5人→6人で150→157kmなら新しい1人の7kmが差分で露出（人数閾値5を満たしても）。
- 同人数でも再集計を繰り返すと変更差分が見える。
- 年間合計と11か月分の差から残りの月の値が出る。既存年間版との照合が必要。
- 5人未満を抑制しても上記差分は残る。
- 同意済みアカウント数は独立した実人間の証明にならない（Sybil）。

## 暫定的な安全境界（PR修正）
`supabase/ranking-month-places.sql` の `ranking_nations_month_places` は定義候補として保持するが、`PUBLIC`, `anon`, `authenticated` の EXECUTE を全て REVOKE。公開UIから呼び出さない。SQLファイルは**未適用**。
DISTANCE/EXPLOREについても本番適用・UI有効化は別承認を要する。
レビューでは関数所有者や他のロール経由の到達性をDBで検証する。

## 次の監査ゲート
1. 個別同意の法的・利用者向け意味とB-1決定との境界。既存年間NATIONSの公開実態を読取調査。
2. 閾値候補（例5/10/20）× 最大寄与率/上位寄与集中 × 丸め × 補助セル抑制を合成データで比較。閾値単独の合格判定は禁止。
3. 同一国でのスナップショット差分、参加/撤回/削除、年/月総計、他公開値との連立推定、外部既知の走行距離、Sybilケース。
4. 通常の月内リアルタイム更新を認めるか、固定スナップショットにするかを別途決定。過去レスポンス/キャッシュとの比較も対象。
5. 表示の有無・順位・参加人数そのものからの推測、0/少人数国、公開グラフやSNS画像を検査。
6. 独立むせ監査で安全性が示せない場合は NATIONS月間の非公開継続。公開に進むには **Atsuoの明示承認** が必要。
