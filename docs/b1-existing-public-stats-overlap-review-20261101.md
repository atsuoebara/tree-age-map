# B-1 現行公開統計と匿名集計の母集団差 — コード照合 2026-11-01

## 照合対象
`supabase/functions/import-share/index.ts`（GitHub mainで読取）、`scripts/b1-anonymity-joint-inference.test.mjs`、B-1設計書。
本記録はコードの意味の照合であり、本番APIへの実アクセス・DB実データ閲覧・むせ監査はしていない。

## 現行公開APIのコード上の事実
- `totalDistanceKm`: `get_import_share_origin_page`から全ページ取得した行で`distance_km>0`の数値を合計。公開API関数には年度や正式同意で絞る条件がない。DB側RPCの具体的な対象条件は**別途確認が必要**。
- `countryDistance`: 同じ取得行のうち有効な開始緯度・経度をもつ記録をADM0の国に割り当て、**ラン全距離を開始地点の1国へ計上**。国境横断ランを分配しない。
- `registeredUsers`: Supabase Authの全ユーザー一覧を数え、国×年の寄与者人数ではない。
- `countryDistance`はISO3キー、B-1審査表は2文字country_codeであり、国コード変換の検証が必要。
- HTTP応答は`Cache-Control: public, max-age=300`。既存公開統計のキャッシュ設定をB-1の撤回可能APIに流用してはならない。
- `totalDistanceKm`と国別距離の差には、国不明/始点欠損なども含まれ得る。差が単一ユーザーの距離とは限らない。

## 連立推定に必要な母集団モデル
B-1セル E = 同意者×確定暦年×検証された対象国距離配賦。既存総計 G = RPCが返す全対象ランの距離。既存国別 C = 同RPC対象のうち開始地点判定が一致したラン距離。
EとG/Cはユーザー集合・期間・国境帰属・欠損扱いが異なる。したがって `G - E = 他人の距離` と短絡しない。一方、公開プロフィールや本人記録を知る攻撃者が非重複成分を推測できれば差分漏洩が成立する。
既存値の反復取得・年をまたぐ変化・参加者自身の既知寄与を含む攻撃モデルを引き続き試験する。

## 次に必要な試験
1. `get_import_share_origin_page` のSQLを確認し、削除/非公開/重複ラン、タイムゾーン、期間等の条件を特定する。
2. 合成の対象集合を「B-1同意×年×国の帰属」と「現行全期間×スタート国」に分けて生成し、重複・非重複寄与を変化させる。
3. 統計の公開履歴・過去5分キャッシュ、外部既知値、複数年を組み合わせた最悪ケースを検証する。
4. 公開値同士が同一母集団だと誤認して等号制約を作る試験を禁止する。一方で、情報不足を理由に差分攻撃の可能性を過小評価しない。
5. 統合試験を経ていないため、匿名性合格・本番公開の判断を行わない。
