# Rings Now — 8日間の境界：マイクロ秒を保持した隔離検証（2026-11-15）

## 判断と適用範囲
- 正式名称は **Rings Now**。内部識別子は互換性のため維持する。
- `public.runs.started_at` は実DBで timestamptz と確認済みで、RFC3339文字列に最大6桁の小数秒が含まれ得る。
- 既存の `Date.parse()` は**ミリ秒まで**しか表現できず、たとえば `.123456` を `.123` に丸め落とす。今回は元の6桁を取得した上で、`BigInt` の**エポックマイクロ秒**として資格判定関数に渡す。UIや元文字列には変更を加えない。
- 現在時刻 `nowMs` と提供開始時刻 `featureStartedAtMs` は**安全な整数ミリ秒**に固定。マイクロ秒の精度があると偽らず、両者を1000倍して `startedAtMicros` と比較する。
- **有効条件**：`nowMs*1000 >= startedAtMicros` かつ `nowMs*1000-startedAtMicros <= 691200000000` マイクロ秒。開始時刻より前／8日超過は遮断。境界を遡って復活させない既存の選択ゲートは維持。
- 例：開始が `08:01:02.123456` の場合、観測する現在時刻が `8日後08:01:02.123` なら境界内（まだ456µs早い）。`8日後08:01:02.124` なら境界外。これは現在時刻の観測精度が1msであることを明示した、比較時点ごとの正確な判定である。
- 既存の `assessImaWoShirouEligibility` はマイクロ秒引数を渡さない隔離呼出しもあるため、以前の整数ミリ秒版を互換維持。今回から `reviewSelectedCalendarRun` 経由では、元のstarted_atから算出した正確な下位3桁を必ず渡す。
