# 「今を知ろう」本番カレンダー導線の隔離実装・完全OFF（2026-11-13）

## 開発上の位置づけ
PR #99 / #100 / #101 / #103 / #104 / #105 は隔離処理と架空UIの基盤。今回初めて `index.html` の**本番カレンダー内部**に、将来の入口を準備する。既存の1本ずつの地図表示 `focusCloudRun(row)` と日付・距離・同日複数本を維持する。

## 非公開の安全スイッチ
- `RR_IMA_WO_SHIROU_CALENDAR_ENTRY_ENABLED=false` は静的定数。URL・localStorage・ユーザー操作でONにできない。
- `RR_IMA_WO_SHIROU_FEATURE_STARTED_AT_MS=null`：本番適用開始境界の承認が未了。仮の日時を注入しない。仮に入口だけONにしても日時未設定なら判定に進まず、利用不可と表示。
- 入口がOFFのため、DOMボタン生成、外部モジュールの動的import、解析、FIT連携、書込などは実行されない。
- 今回は内部導線だけ。本番の適用開始日時・色分け・日英完成UI・実FIT照合・データ品質・iPhone実機検証は**未決定／未実装**。

## 正確な仕様の継承
「今を知ろう」は表示名、「1km解析」は内部、「ガチラン」は本人が自分で選ぶラン。対象期間は`started_at`から691200秒、8日ちょうど有効、超過失効、遅延取込で延長しない、過去活動へ遡及適用しない。信号・トイレ等の休憩は一律除外せず、停止を含む時計経過を使い、自動ポーズ等による不正確さは注意書きで示す。停止を勝手に補正したり数値を捏造しない。11月12日以前の停止一律除外は不採用。

## リスクと監査
`index.html` の既存カレンダー回帰テストを必須とする。新しいボタンは元のボタンを置換しない。本人ID、カレンダーの表示状態、対象の日付、削除・行の存在を確認し、動的import後にも再検証する。OFF状態での表示影響ゼロを必須とする。

これは隔離開発から「将来本番に結線する」ための最初のコードであり、**実際に使える機能の公開ではない**。本番HTMLに差分が生じるため、むせ独立監査・Atsuo明示承認まではDraft保持、マージ・公開なし。仮に後日マージしても安全スイッチをONにするには別の監査・承認が必要。

## むせへ
1. 新入口が`false`に固定され、実際の利用者に表示されないこと、未指定境界でfail-closedになること。
2. `focusCloudRun(row)`、同日複数本、既存日付・距離、カレンダー月移動、ログアウト時の所有者保護の退行がないこと。
3. 動的import後のユーザー切替・日付切替の競合と、URL等での有効化の可能性。
4. 既存FITから保存済みランへの自動リンクや、根拠のない1km値が追加されていないこと。
5. `node --test tests/ima-wo-shirou-calendar-entry-disabled.test.cjs` および `node scripts/test-run-record-calendar.cjs` を実行。
6. 日英、iPhone実機、未決定ロールアウト日時、品質認定の保留が適切に明記されていること。
