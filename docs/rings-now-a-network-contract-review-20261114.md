# Rings Now — 方式Aの匿名通信契約案（採用未決定）
2026-11-14 / review-only / parent main ca94c5104be78981a057081372972354f5562568

## 目的
一般ランナーが将来使える「Rings Now」を目標とする。PR #130で比較した方式A（制御通信あり）を**採用せず**、どの通信情報が必要か、何が未検証かを小さな合成契約として可視化する。実FIT・個人情報・実HTTP・公開ページ・サービスワーカー・DBは扱わない。

## 合成契約
架空の要求は `{protocol:"rings-now-review-v1",build:"v1"}` のみ。FIT、GPS、距離、心拍、時間、アクティビティID、アカウントIDなど追加フィールドを拒否する。受信する架空の応答は `{protocol,build,enabled}` のみ。通信失敗・オフライン・検証できない信号・機能停止・版不一致・余分な応答フィールドはすべて遮断。検証済みシグナルという条件自体は**仮定であり、検証方式は未実装**。肯定的な結果も `requires_manual_review` が上限で処理許可は出さない。

## プライバシーの未検証
アプリ側でFITや識別子を要求本文に入れなくても、実際のHTTPにはIPアドレス、User-Agent、時刻、リファラー、アクセスログ、キャッシュ記録等が残り得る。端末と通信先の設計、送信頻度、ログ保持、CORS、Cookie、認証、リファラー、URLクエリ、TLS、CDN・SW・HTTPキャッシュを監査するまでプライバシー保証なし。独立監査・本人承認なしに通信先も作らない。

## 旧タブ停止の限界
通信を実装しない旧タブには照会を強制できない。通信機能を持つタブもオフラインやスリープ時に停止通知を受けられない。将来「解析直前に照会する」設計を検討する場合でも、キャッシュと処理中断、bfcache復帰、既存タブの限界をiPhone Safariで実証する必要がある。今回のモデルは実ネットワークや旧タブ停止を検証していない。

## 費用と運用の未検証
方式Aは0円を保証していない。候補配信先の無料枠・リクエスト上限・転送量・ログ保存・レート制限・障害時挙動・悪用負荷・利用規約を確認し、追加費用が発生しない実証が必要。費用を保証できない場合は採用しない。実サービス／APIエンドポイントは追加しない。

## 不変条件 / 監査
今回追加するのは新規4ファイル（合成モデル、Nodeテスト、この文書、CI）のみ。公開HTML・index.html・sw.js・DB・カレンダー・解析エンジンは変更なし。実FIT未使用・未承認、Rings Now本番OFF、PR #109 HOLD。全判定で `realFitAllowed=false`、`productionAllowed=false`、`verifiedSafe=false`、`adopted=false`、`oldTabGuaranteedStopped=false`。むせの独立監査と本人承認前にマージ禁止。
