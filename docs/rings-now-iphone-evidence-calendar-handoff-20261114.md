## 2026-11-14の本人決定を継承
- 正式名称：**Rings Now（リングスナウ）**。**NOW（今） × KNOW（知る）**。以前の「今を知ろう」は旧称。互換性のため内部識別子を無差別に変更しない。
- **iPhone最優先**。PCは任意の開発補助。PR #109はHOLD。
- Runner's Rings既存のカレンダーから本人が個別のガチランを選択する。別カレンダーの新設・自動選択は禁止。
- 期限：走行 `started_at` から8日 = 691200秒。過去のランを後からFIT取込で再認定しない。`featureStartedAtMs` は本番ON承認前には `null` を維持。
- 信号待ち・トイレ休憩を理由に一律除外せず、区間は停止を含む時計経過時間。データ欠損を補間・補正・捏造しない。実データの品質認証は未完。
- 実FITの本人選択があっても**選ばれたFITと保存済みカレンダー行の同一性を勝手に推測しない**。ファイル選択と記録選択は異なる操作であり、同日・距離近似だけで自動結合しない。
- 現在の実ページに本番Rings Now導線を表示しない。`RR_IMA_WO_SHIROU_CALENDAR_ENTRY_ENABLED=false`、`RR_IMA_WO_SHIROU_FEATURE_STARTED_AT_MS=null`を保持する。

## 次の接続工程の判定条件（このPRでは接続しない）
1. 既存カレンダーの表示・地図ボタン `focusCloudRun(row)`、日付・距離・同日複数の個別行を保持する。
2. 個別行から選んだ本人・ユーザーID・走行開始時刻・8日期限を、非同期処理の前後で再検証する。ログアウト、表示日・月の切替、行削除、所有者変更時は失効させる。
3. 合成FIT試験ページ（`previews/rings-now-iphone-synthetic-only-20261114.html`）は**本人実FITに使わない**。将来の実FIT入口・配信は別の設計／監査が必要。
4. 解析候補は `qualityCertified:false`、`analysisAllowed:false`、`writeAllowed:false`。実FIT保存・DB・クラウド通信を新設しない。
5. 本番への接続前にむせ独立監査→Atsuo本人明示承認。コード／DB／SWの変更は別PRで。公開ページは現在の合成専用を維持する。
