**状態:** 提案・未承認。匿名性の安全性を認定しない。実ユーザーの分布未取得。本番Supabase変更、同意受付、数値公開は禁止。

## 公開判断の原則
各国×完了年セルを「保留 / 不合格 / 審査通過候補」の3状態で扱う。**この草案では「公開可」を出さない。** 最終的な公開許可には、独立監査、実分布確認、Sybil評価、同意・撤回・配信統合試験、Atsuoの承認が必須。
- 観測者は公開済みの旧版、国別・全体統計、過去5分のキャッシュ、複数年度セル、本人・外部既知の走行距離を入手可能と仮定。
- 同一母集団でない統計を誤って等式で結ばない一方、非重複部分の既知化を脅威に含める。
- 攻撃者別に特定個人の寄与区間 [L,U]、幅 U-L、存在有無の推定、属性の識別リスクを記録。上限不定・観測不能も安全とみなさない。

## 合成試験の暫定『即時不合格』ライン（**安全ラインではない**）
- 個人の寄与を一意に復元できる、または丸め/複数公開値の連立で **0〜500km幅** に狭められるシナリオが一つでもある → 不合格候補。500kmは試験の警戒値（監査で変更可能）であり、501km幅なら安全という意味ではない。
- 年度差分、旧/新スナップショット、既存公開統計の時系列などで、特定の活動・参加の存在が外部情報と結びつく場合 → 数値幅に関係なく不合格候補。
- 独立参加者数が検証できない、上位寄与の支配や複数アカウントの影響を排除できない、あるいは攻撃モデルを検証できない → 保留、公開禁止。
- 人数・寄与集中・丸め候補（最低人数 5/10/20/30/50/100、最大寄与10/20/30/40%、上位2/3人30/40/50/60%、丸め100/500/1000/5000km）のグリッドは探索の入力値に限る。採用閾値ではない。

## 受入条件の確定前に必要なエビデンス
1. 合成データの複数年・時系列・既存統計・既知寄与を組み合わせた最悪可行区間の探索、攻撃者が既知の参加者である場合、複数未知のケース
2. 寄与者人数・上位寄与集中度・国×年セル数などの実分布（事前承認の読み取り限定、詳細値はGitHubに残さない）
3. Sybilの個別設計と偽アカウント・誤除外の検証。追加本人確認書類を初期要件にはしない
4. 数値受入閾値の妥当性と、匿名化できない場合は『数値表示なし』の選択についてむせの独立監査
5. 撤回時の原子的失効・配信停止と実HTTP/no-store/キャッシュ試験

## 第6回独立監査への修正（v0.3、2026-11-01）
**本節は審査草案であり採用基準・公開許可ではない。**

### 絶対幅・相対幅・区間位置の複合評価
個人の寄与に対する推定区間 [L,U] について、幅 W=U-L の絶対値と本人の年間寄与に対する相対幅の両方を評価する。本人の真の値を攻撃者が知らない場合、候補範囲全体で最悪となる相対的な絞り込みも評価し、0や極小値の分母を勝手に代入しない。**相対幅の採用割合は実分布評価・独立監査後に決定し、絶対幅だけでは基準を確定しない。** 幅500km以下は引き続き暫定警戒ラインであり、500km超を安全とは見なさない。丸め刻みを大きくすると公開値の有用性が下がるため、丸め幅と警戒ラインを独立に採用しない。
記録には W のほか L・U・区間が示唆する活動量の属性（例：高距離走者）・複数年/複数国の行動パターン推定・既知情報を結び付けた推定可能性を残す。人数・距離の個別値を公開レポートに転記しない。

### 存在推定・抑制セルの表示
公開対象から外した国×年セルについて、人数不足・支配性・同意撤回等の**非公開理由を表示しない**。国×年セルの有無や抑制された事実自体が少人数参加を示唆する可能性があるため、同じ一般的な「表示できる集計はありません」という状態を用い、セルの存在を列挙しない案を独立審査する。年度・国別の差分や複数セルから参加/活動パターンが結び付く経路が一つでもあれば不合格候補。観測可能な経路と、その情報により存在の確信度がどう変化するかを記録する。

### セル単位・機能単位の停止条件
1. 連立モデルで1人でも一意復元・暫定警戒値以下の最悪幅・相対幅での危険・属性/参加の識別が判明したセルは**非公開**。未検証は保留＝非公開。
2. Sybil評価が完了しない場合は**全セル保留**。アカウント数を独立人数と扱わない。
3. 実分布評価後に、全条件を満たす公開候補が極端に少なく、国×年の数値を提供する価値より連立推定リスクが大きい場合、初期リリースから**国×年の数値公開機能を除外**する判断をAtsuoへ諮る。
4. 旧版との比較・撤回停止・キャッシュ・他統計の重ね合わせを評価できない場合も配信しない。
