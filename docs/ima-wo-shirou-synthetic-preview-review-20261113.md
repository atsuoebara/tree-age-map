# 今を知ろう：カレンダー風の隔離UIプレビュー（2026-11-13）

## 目的
PR #100/#101/#103/#104がmainに統合され、既存カレンダー自体は未結線。本人のガチラン選択・同日複数本・8日期限・異常時の表示がスマートフォンでどのように見えるか、実データへ触れずに検査する。

## 範囲
`previews/ima-wo-shirou-calendar-synthetic-20261113.html` は架空データ専用。ログインなし、外部通信なし、DBなし、FIT/Garmin連携なし、保存なし。既存カレンダーのタブ・地図遷移・配色は変更せず、`index.html`, `sw.js` も無変更。
`src/ima-wo-shirou-calendar-selection-review.mjs` を**相対import**して既存の隔離8日ゲート経由で選択状態を検証する。開始境界と現在時刻は**架空デモの固定値**であり、本番の適用開始日時ではない。

## 決定事項／却下案
機能名『今を知ろう』、内部処理『1km解析』、対象『本人が選ぶガチラン』。停止/信号/トイレがあっても一律除外しない。停止を含む時計経過、手動／自動ポーズの影響で正しく解析できない場合があると注意。停止時間補正、数値捏造をしない。古い『停止＝除外』案は不採用。
期限は走行開始から8日、境界ちょうど有効、超過で失効。取込日時で復活させない、既存過去記録を遡及しない。既存の`activity_date`はカレンダー日付、`started_at`は期限判定。デモはこれらの区別を説明する目的で、実際の記録ではない。

## 監査依頼
1. 模擬データ以外を一切参照せず、ネットワーク・保存・実FITなし。
2. 同日複数本を個別選択し、本人選択なしに自動ガチランとしない。
3. 8日ゲートが期限内でも`analysisAllowed:false`を保持。診断結果の捏造なし。
4. 自動ポーズ等の注意書きが本人決定文と完全一致。
5. iPhone狭幅画面で横はみ出し、選択、状態表示を確認（静的テストだけでは実機を保証できない）。
6. `node --test tests/ima-wo-shirou-ui-synthetic-preview.test.cjs`、既存のカレンダー回帰テストを実行。むせは読み取りのみ、本人明示承認までマージ・公開なし。
