# Runner’s Rings ブランド・開発の基本方針
2026-11-13 / Atsuoの既存方針を言語化 / 本番公開は独立監査と本人承認後

## ブランドの核（変えない）
**努力を可視化し、努力の先へ。**

走った道が年輪となり、積み重ねた努力が見える。そして「次も走ろう」「次はどこを走ろう」と思えること。ランリングは初心者、ゆっくり走る人、競技者、再開した人まで**すべてのランナー**を対象とし、タイムや速さだけで価値を決めない。

## 開発の姿勢
**努力は真剣に。楽しさは全力で。**

ランナーの挑戦・積み重ねは真剣に受け止める。一方で、下手うまGPSアート、笑えるJournal、開発者のユーモアを大切にする。笑うのは本人の努力ではなく、その道の形や意外な発見や開発のドタバタ。笑いを口実に努力を茶化さない。

## 差別化
- **「専門的な分析？ そこは大手に任せます（笑）。」** は開発者メッセージのキャラクターとして使用できる。専門サービスへの敬意であって、Garmin/Stravaを貶める趣旨ではない。
- Runner’s Ringsは分析精度・指標数の競争を目的にせず、走った証、記憶、年輪、仲間の輪、次の一歩のきっかけを磨く。
- ガチラン等の振り返り機能はあくまで任意の補助。停滞・トイレなどの時計経過時間を含め、ポーズ注意を簡潔に伝える。これをサービス全体の中心に据えない。
- **走った証を、次の一歩の力に。** はユーザーに向けたメッセージとして使う。

## 掲載先別の使い分け
1. `about-runners-rings.html`：万人向けの理念。「努力を可視化し、努力の先へ。」と走った証への敬意を中心に、日英の対応表記で明記。
2. `developer-message.html`：本人の人柄と遊び心。「専門的な分析？ そこは大手に任せます（笑）。」「努力は真剣に。楽しさは全力で。」を本文で使用し日英対訳を併記。
3. `team.html`：「3人の約束」に開発判断の基準として追記。既存の個人情報・品質・人間の最終判断の記載を維持。
4. 将来的な機能説明・Journal・プロモーションも、この方針と矛盾しないこと。ただし**全ページに同じ文章を機械的に連投せず、ページの役割に合わせる**。

## 守ること
- 既存コピー「ランナーの努力を、年輪として可視化するアプリ」「走った年輪から、世界に仲間の輪を。」も残す。
- 既存の認証、Strava/COROS/Garmin/Connect IQ、年輪、Journal、収益導線を変更しない。
- 日本語/英語双方で意味が揃うこと、スマホで読みやすいこと、文体の誇張を避けること。
- 広告・プライバシー・利用規約・既存機能を壊さず追加費用を増やさない。
- PRは独立監査を経てAtsuoの明示承認後に限りマージ。監査者への直接送付とGitHubへの記録を混同しない。
