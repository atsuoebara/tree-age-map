# A-4 第5弾 P0：対象外記録の内訳可視化・独立コード監査依頼（2026-11-05）

**状態：試作、未マージ・未公開。第5弾のP0のみ。P1原本評価、P2本人確認の保存、P3認定の反映は未実施。**

## 目的
本人専用の「年輪の節」パネルに、取得済み保存レコードの**対象外内訳**を取り込み元別の件数だけで提示する。Nike+時代に由来する可能性のあるTCXと、その他の対象外を区別する。本人が違いを理解できるようにする一方、現行の認定対象や記録は一切変更しない。

## 実装
- `a4-milestones-core.js` に読み取り専用の純関数 `eligibilityBreakdown(rows, verifier)` を追加。現行の `verifiedImportedRun` と同一の適格性・有効な開始日時を使って、対象／対象外を分離。元の行を変更せず、合計件数と理由コードごとの件数のみを返す。
- 件数区分：TCX、取り込み元不明、Garmin、Intervals、Strava ID未確認、開始日時不正、その他。対象外ソースは推定で「Running」にしない。
- 入力の同一IDが重複していたり不正なIDがあれば、集計を安全側に停止（認定済みの初30km／100回目／500本刻みには波及しない）。
- `a4-milestones-preview.js` の既存本人専用パネル最下部に、初期折りたたみの `<details>` を追加。「対象外の記録の内訳を見る」を押すと、保存済み数／認定対象数／対象外数／内訳を表示。日英対応。個別の日時・名称・GPS軌跡は表示しない。
- 既存 `fetchCloudRuns({stableOrder:true})` の取得結果を共用し、追加API呼び出し・新しいDBテーブル・保存・個別ログ出力・外部送信を行わない。全件取得失敗時は内訳もエラー表示。
- ログアウト・アカウント切替時に内訳と表示状態を消去。表示言語変更時は同じ検証済み集計結果から表示を再描画。
- `index.html` のA-4スクリプト2本のキャッシュ版数を更新。他の主要UIや同期ロジックは変更しない。
- A-4「節目」の日付・回数の現行認定には**一切反映しない**。P1以降の実装は別ゲート。
