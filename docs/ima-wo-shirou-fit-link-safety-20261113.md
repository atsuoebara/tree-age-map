# 「今を知ろう」カレンダー行とFIT候補の結線安全ゲート — 2026-11-13

## 発見した未解決条件
既存カレンダー`fetchCloudRuns()`は保存済み`runs.id, user_id, activity_date, started_at, distance_km, source`等を返す。しかし生FITの1kmレコードをカレンダーの行から自動取得できるという証拠はない。PR #99の`reviewSingleUserFitBuffer`は本人が**別途選んだ**FITファイルのローカル候補を返し、`status:'candidate_unverified'`かつ`analysisAllowed:false`。両者が同じ活動であることを自動推定してはいけない。

## 今回の隔離試作
`src/ima-wo-shirou-fit-link-review.mjs`は2つの試作結果を受け取るだけで、ファイルも通信も読み込まない。
- 期限内かつ本人選択済みの単独カレンダー行であることを前提とし、選択IDが変更された場合は拒否。
- FITは品質未認定で書込も解析許可もない`candidate_unverified`のみ受ける。
- 本人が「同じランのFIT」を明示的に確認しなければ、ローカルプレビューすら許可しない。
- 本人が確認しても`linkVerified:false,analysisAllowed:false,writeAllowed:false`。本人確認はFIT本人所有やデータ正確性の独立認定ではない。
- 出力は状態と日英注意書きのみ。ランID、GPS、FIT元データ、1km数値を他のストレージやAPIに送らない。

## 最新会話決定の優先順位
2026-11-13：『今を知ろう』は機能名、1km解析は内部処理。ガチランの選択は本人だけ。開始時刻から691200秒以内（境界含む、超過不可）。遅延取込による延長なし、過去記録への遡及なし。信号・トイレ休憩だけで一律除外せず、停止を含む時計上の経過時間で見る。自動ポーズ等には「信号待ちやトイレ休憩、自動ポーズなどの影響により、正しく分析できない場合があります。」と注意する。時間補正・データ捏造はしない。2026-11-12以前の一律除外候補は採用しない。

## 限界と保留
これは結線前の安全ゲートであり、**カレンダーへの実ボタン、FITとの実際の一致照合、品質認定、1km解析の本番出力ではない**。実FITの取得・本人同一性の保証や、開始時刻の適切な適用開始境界は未確定。別々の試作が使用可能でも本番連携は承認されない。既存カレンダー、Garmin OAuth、DB、保存・通信、本番画面はすべて無変更。追加費用0円。
