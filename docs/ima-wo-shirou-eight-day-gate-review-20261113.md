# 今を知ろう：8日間の期限ゲート（独立試作・2026-11-13）

## 決定と会話の背景
2026-11-13の本人合意：機能は「今を知ろう」。内部処理は「1km解析」、本人選択した対象が「ガチラン」。年輪で可視化した努力から次の一歩につながる振り返りを提供する。自動判定しない。

期限は走行開始から8日（691200秒）。ちょうど8日で有効、超過で失効。遅延取込で復活しない。過去ランに遡及しない。終了した対象には診断を出さない。

## この差分
- `src/ima-wo-shirou-eight-day-eligibility.mjs`：副作用のない期限・本人選択判定のみ。
- `tests/ima-wo-shirou-eight-day-eligibility.test.mjs`：境界、遅延取込、過去記録、本人選択、不正時刻の回帰テスト。
- 使用時は必ず呼出側から `maxAgeSeconds: 691200` を渡す。未指定／異値は拒否。
- `featureStartedAtMs` は**未決定の本番適用開始境界**。適当な日付をハードコードしない。呼び出し側が明示しなければ拒否。
- `startedAtMs` は走行開始のUnix時刻（ms）。既存カレンダーの `runs.activity_date` を時刻に変換して代用しない。
- `analysisAllowed:false` は期限判定が品質認定や本番解析許可と混同されるのを防ぐため。期限内かどうかと、分析可能かどうかは別条件。

## 2026-11-13新決定の優先（本差分は1km解析自体を変更しない）
信号・トイレだけで対象外にしない。停止時間を含む時計経過時間を扱い、自動ポーズ等がある場合は「信号待ちやトイレ休憩、自動ポーズなどの影響により、正しく分析できない場合があります。」と注意。停止を自動除外・補正せず、解析不能時は数値捏造禁止。11/12以前の一律停止排除方針を復活させない。
