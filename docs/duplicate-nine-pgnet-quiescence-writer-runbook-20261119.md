## pg_net freeze gate (mandatory, proposed)

1. Do not issue any DML until separate operator, security and owner approval. Identify private IDs of the **9 Intervals target rows and 9 Strava survivors**, do not publish them.
2. Put the **target owner's** new source writes under a scoped hold (how must be defined and tested). Prevent new Today trigger enqueues via a narrow, independently audited maintenance path; do not modify the trigger as a side effect of drafting. A soft delete itself fires the live trigger unless properly isolated.
3. Wait for affected GitHub jobs to finish or be explicitly stopped safely. Confirm **0 queued/in-progress** relevant Actions runs, including delayed schedule and manual dispatch.
4. For `net.http_request_queue`, use privileged read-only inspection that filters only the Today live endpoint and **privately** examines `body` for the target nine IDs (never expose body tokens). Require **0 target requests**, and for strongest conservative gate **0 endpoint-wide requests**, across **two or more successive observations** after enqueue suppression. Presence of any such request => **BLOCK**, do not simply delete it.
5. The queue count of zero is insufficient to prove the worker is idle. Independently inspect inflight pg_net worker / edge-function execution logs and timeout/retry window; require **0 active target requests**, no late retries, and a quiet duration **at least the verified maximum request timeout plus any real retry slack**. The trigger uses a 30,000ms request timeout, but overall retry behavior is **not verified** and must be settled before choosing a quiet duration.
6. Record a private manifest of dependent rows (counts + hashes) **after** the quiescence gate. Check again immediately before a final approved single-transaction DML. Any count/hash drift, newly queued request or job => **BLOCK** and restart freeze + evidence process.
7. Do not claim full freezing merely because a read-only snapshot had 0 queued endpoint requests. All gates must be evidenced under the actual approved stop conditions.
