## 1. 目的と会話の背景
Runner's Ringsの理念は「ランナーの努力を可視化し、努力の先へ。」。走った道の年輪に加え、本人が選んだ真剣なランを振り返る機会を提供する。高度な分析で大手と競争するのではなく、ランナー自身の振り返りに役立てる。「努力の先へ」の会話の経緯を仕様の文脈として監査に添える（この文章は逐語録ではなく決定事項の要約）。

## 2. 用語（確定）
- **今を知ろう**：表示上の機能名。
- **1km解析**：Garmin由来の利用可能なデータを1km区間に分ける内部処理の説明。別の公開機能名にはしない。
- **ガチラン**：本人がガチランと判断した個別のラン。自動分類・自動推薦対象の選定をしない。
- 「ガチラン分析」「1km分析」など新たな並列機能名は作らない。

## 3. 期限（確定）
- 走行**開始時刻**から **8日 = 691,200秒**。呼び出し側は `maxAgeSeconds = 691200` を明示して渡す。
- 差が691,200秒ちょうどなら有効。1秒でも超えれば失効。
- 後から取り込んでも有効期間は復活しない。過去アクティビティへの遡及適用なし。
- 期限切れのランには診断を出さない。
- カレンダーに表示する保存済み日付 `runs.activity_date` と、診断期限判定に使う走行開始時刻を混同しない。開始時刻が信頼できないときは日時を捏造せず、判定の実装方針を別途検証する。

## 4. 停止・計測欠損（11/13更新決定、旧方針より優先）
- 信号待ち・トイレ休憩だけで対象外にしない。
- 1km区間の時間は、停止時間を含む**時計上の経過時間**を扱う。moving paceと誤称しない。
- 自動ポーズ・手動停止の影響で正しく分析できない可能性を注意書きで伝える。推奨文：
  **「信号待ちやトイレ休憩、自動ポーズなどの影響により、正しく分析できない場合があります。」**
- 停止した時間を勝手に除外・補正しない。停止原因をデータから断定しない。
- 本当に解析不能な入力は数値を作らない。
- **却下した旧方針**：停止候補があるというだけで一律に分析対象から排除する方式。2026-11-12の混合品質・連続性の隔離試作は2026-11-13の採用方針に自動昇格させない。
- 未決定：停止／ポーズ情報が時計経過時刻に欠けるFIT実データの取り扱い、各品質フラグから実際に何を表示可能とするか。実例・独立監査を経て決める。
