# レース分析から一般的な練習を紹介する機能（隔離プロトタイプ）

作成：2026-11-12。**設計・純粋関数のみ。未公開、実データ未接続、追加費用0円。**

## 目的
1km区間の結果を振り返ったランナーに、一般的な練習方法を**理由付きで最大3件**紹介する。診断、故障原因の推定、練習処方、効果保証はしない。

## 現在の暫定ルール
- Garmin累積距離の「完全な1km区間」だけを対象にする。端数区間は除外。
- 時計経過時間（停止を含む）を使用する。移動ペースや公式レースラップとは呼ばない。
- 6区間以上かつ全完全区間で valid / qualityOk の場合のみ判定。そうでなければデータ不足として提案しない。
- 全区間を前半・後半に二分し、それぞれの中央値を比較する。後半/前半が1.10以上なら「後半の経過時間が長い」→ゆっくり長く走る練習／一定ペース走、0.90以下なら「後半の経過時間が短い」→一定ペース走、それ以外は「比較的均等」→イージーラン。
- 閾値10%は **製品検証用の仮値** であり、医学的・スポーツ科学的に最適と証明された基準ではない。監査・実測前に本番接続しない。
- 停止、信号、コース、高低差、天候、補給、疲労などの影響を判別できない。原因を断定しない。
- ユーザーの負傷・疲労・直近の大会日程に合わせた個別処方は行わない。痛みがある場合は強度を上げるよう勧めない。
- 数値がない、欠損・品質不十分の場合は「データ不足」とする。架空値で穴埋めしない。
