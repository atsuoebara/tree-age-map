- **準備フェーズ（スマホで可能）**：既存文書・SQL・#153パーサーの参照を固定 → 手順・テスト台帳・合成fixtureを作成 → むせ独立監査 → 費用/安全性/所要時間の事前判断。

## 4. PC作業を短縮するための判断
- PCを使用できる日が未定のため、所要時間は**未見積**。短時間完了を保証しない。
- Docker利用不可の場合にクラウド環境へ自動切替しない。GitHub Actions等は課金と実行上限、秘密管理、再現性を先に監査し、別途承認が必要。
