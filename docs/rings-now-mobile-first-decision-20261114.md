# Rings Now（リングスナウ）：正式名称・語源・スマホ最優先（2026-11-14）

**本人の確定決定。実装・本番公開の承認とは別。**

## 名称の決定と由来
- **正式な表示名：Rings Now（リングスナウ）**。
- **二重の意味：NOW（今） × KNOW（知る）**。本人の説明は「今のナウと知るのナウ」。単なる「現在」の now だけではなく、自分の今を知る、という製品体験を表す。
- 過去の機能名「今を知ろう」は**旧称**。以前の決定文書や監査履歴を削除・改竄せず、後続の公開文言を新名称に置き換える。
- `ima-wo-shirou` など既存ファイル名・モジュールIDは内部互換性のため、**無差別にリネームしない**。UI公開名と内部識別子を分離する。
- 「1km解析」は内部の処理説明。「ガチラン」は本人が自分で選ぶ対象ラン。Now と Know の二重の意味も、医学的・専門的な走力診断を保証する表現には使わない。

## PC利用を必須にしない
2026-11-14本人「何故PC?」という指摘により、チャッピーは既存のWindowsローカル検証バンドル再利用を主導線のように進めた点が、Runner's Ringsの「スマホ最優先」という基本原則と合わないことを認め、修正した。
- 最終体験は**iPhoneを優先**。既存カレンダーから本人が1本選択し、可能な限り端末内でデータを扱うことを目指す。
- PCは開発・技術検証の**任意の補助**であり、本番利用の必須要件にしない。
- iPhoneでのFIT端末内読み込みが安全に実装可能か、実行環境／配布方法／実機検証が未完了。できると決めつけず、別途監査する。
- PR #109はWindowsバンドルの条件付き使用説明を更新しただけ。CI成功でも**PCを必須経路として採用しない／HOLD**。独立監査、本人承認までマージ・実データ解禁禁止。

## 既存の確定条件を引き継ぐ
- 本人が選んだ個別のガチランのみ対象、8日間（走行開始 `started_at` から691200秒、ちょうど境界は有効、超過無効）、取込延長や過去記録への遡及なし。
- 信号待ち・トイレ休憩だけで除外しない。時計経過は停止時間込み。自動ポーズ等により正しく分析できない場合があると注意を示す。停止原因を断定せず、欠損値の捏造をしない。
- 本番カレンダーの既存の距離・ルート移動・同日複数本・色を壊さない。新しい入口はPR #106の時点でOFF固定、本番を勝手にONにしない。
- FIT、GPS、心拍、生データは、本人の意図しないネット送信・DB保存・GitHubアップロードなし。追加費用ゼロ。
- むせの独立監査 → Atsuo本人の明示承認 → マージ／本番変更、という順序を厳守。
