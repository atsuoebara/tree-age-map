# ガチラン：努力の可視化 → 次も走りたくなる（最小実装方針）

2026-11-13 / オーナーの会話で決定 / Draft PR #67 / **本番反映は未承認**

## サービスの原点
Runner's Ringsは「ランナーの努力を、年輪として可視化するアプリ。」であり、その結果として「次も走りたくなる」ことが目的。速いランナーや大会参加者だけを対象にしない。初心者、ゆっくり走る人、久しぶりに走る人、記録を狙う人の努力を等しく扱う。ガチランは年輪を補う任意の振り返り機能であり、サービス全体の主役ではない。

## 最小機能（MVP）
- カレンダーから**自分で走行記録を選ぶ**。既存年輪・ランの保存と表示を変更しない。
- データがある場合、1kmごとの経過時間/ペースを分かりやすく表示。心拍・ピッチ・パワーは**取得できた項目だけ**表示、無い項目は「データなし」。計測できなかった値を作らない。
- 長距離であれば、序盤と終盤のペース変化など、**事実に基づく短い振り返り**を添える。大げさな能力評価、優劣、専門的な診断・トレーニング処方はしない。
- 努力が見える画面の最後は、ランナー本人が「次も走ろう」と思える穏やかな振り返りにする。記録が悪くても責めず、根拠のない褒め言葉や記録更新を捏造しない。
- Garmin・COROS・Strava・FITなどの既存入力経路は維持。Stravaが使えない人を排除しない。新しいStrava streamsの分析利用は公式回答が来るまで禁止。

## 表示する注意書き（確定）
> 1kmごとのペースは、立ち止まった時間やトイレなどの時間も含めた経過時間をもとに計算します。
>
> ※自動ポーズや手動停止を使用した記録は、正確に分析できない場合があります。

※経過時間を算出できないデータでは、適当な数値を作らず「この記録では区間分析ができません」と簡潔に案内する。すべての停止ケースを完全再現する高度なイベント復元はMVP対象外。

## やらないこと（現段階）
- Garmin ConnectやStravaと高度分析の細かさを競わない。
- 停止・再開・自動ポーズの例外を延々と掘り下げない。既存の隔離安全診断は残すが、新たな停止イベント仕様を優先しない。
- 初心者やジョグ利用者に専門的な指標や競争的評価を押し付けない。
- 大量のデータや高コストなAI解析を自動実行しない。必要なら利用者がチャッピーに個別に相談すればよい。

## 実装の優先順位
1. **まず努力が見える最小の画面設計**：距離・経過時間・1kmの変化（利用可能なとき）・簡単な振り返り・再び走る意欲につながる導線をスマホで読める形にする。
2. データ欠損と二重取り込みの既存安全策を維持し、本人が選んだ記録を上書きしない。
3. StravaのAPI規約・Garmin再認可の公式回答、むせ独立監査、オーナー承認を満たすまで本番連携・実データ取得・保存は追加しない。

## Doneの定義
- 初心者でも迷わず見られる。
- 走った本人が自分の努力を理解できる。
- 正確でない数字を「正確」と装わない。
- 次も走りたくなる。ただし誇張・ランキング強制をしない。
- 既存の年輪・通常の取り込みが壊れない。
