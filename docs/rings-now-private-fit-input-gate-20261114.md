# Rings Now：iPhone内の本人実FIT入力ゲート（隔離試作） — 2026-11-14

## 位置づけ
**iPhone合成FITの実機確認（PR #112・#113）を経た次工程。実Garmin FITは未検証・使用未承認。** 
`src/rings-now-private-fit-input-gate.mjs` は本人が選ぶ1本のFITを将来ブラウザ内で調べるための**独立した非公開UI用モジュール**。本番の`index.html`、合成専用プレビュー、既存FITプレビュー、サービスワーカー、DBは一切変更せず、どの公開ページからも呼ばない。リポジトリ内に置かれたソース自体は静的配信で閲覧可能となり得るので、「秘匿されたコード」「認証された画面」とは主張しない。

## 安全条件
1. `confirmedOwner` と `confirmedGachi` の明示的確認が両方必要。検証対象の自動選定なし。
2. `.fit` 拡張子、16バイト以上16MiB以下、ファイル選択時の実バイトサイズ一致を確認。ZIPや規格外サイズは拒否。
3. `isSelectionCurrent` が必須。非同期ファイル読み出し前・後、FITデコード後に再確認し、別ファイル選択・画面離脱・所有者切替などで呼び出し側が失効させられる。将来のUI側にはこのガードを正しく実装する必要がある。モジュール単体ではユーザーセッションを読み取らない。
4. 既存 `reviewSingleUserFitBuffer` を再利用し、`candidate_unverified` かつ `qualityCertified:false`、`analysisAllowed:false`、`writeAllowed:false`、`providerDataCombined:false` のときだけ`reference_only_unverified`を返す。解析できても正式な走力診断ではない。
5. 外部送信、DB書込、ストレージ保存、Garmin API、Strava、GPS/心拍/生時刻列の返却なし。返却は参考候補の区間数値と警告だけ。ファイルの名称やバイナリを返さず、ファイルを保管しない。
6. **カレンダー記録への自動紐付け禁止**。FITと保存済みランの同一性は日時・距離近似で判断しない。`started_at`から8日以内かどうか、ロールアウト開始時刻、本人所有かどうかを判定する既存カレンダーアダプタは別の境界であり、**このゲートだけでは本番診断を許可しない**。
7. 信号待ち・トイレ・自動ポーズに伴う時計経過やサンプル欠損は、既存の未認証解析の品質フラグに委ねる。停止時間を勝手に差し引かない。

## 検証の範囲
`tests/rings-now-private-fit-input-gate.test.mjs` では合成FITのみ使い、二重確認、規格外の拒否、非同期中の選択失効、既存SDKによる5区間、許可不能な出力の拒否、公開ページからの未接続をテストする。
**iPhone実機で実FITを使ったこと、Garminの機種・自動ポーズ・セッション起点の品質保証、ブラウザでのネットワークパケットの不存在を証明するものではない。**

## 将来の実データ試験前に必要な独立判断
- 実FITを扱えるiPhoneのUI配信元・HTTPS・CSP・キャッシュ／SWの動作と認証やアクセス境界（合成専用ページを流用しない）。
- 本人に何を確認させるか、ファイル選択とカレンダー選択の関連付けの検証方式。必要なら中止できること。
- 実FITを**本人端末内でのみ**扱い、第三者サイトへアップロードしない具体的な導線。
- Garminの実FIT（2026-11-03ぐんま等）を使う場合は、**期限を超えた本番診断ではなく隔離品質検証のみ**。本人とむせが別途承認するまで実FITを開かない。
- モバイルメモリ、容量、処理中断、画面ロック、ログアウト、権限切替の実機テスト。実データをログやスクリーンショットに含めない。
- 本番機能は`RR_IMA_WO_SHIROU_CALENDAR_ENTRY_ENABLED=false`、`RR_IMA_WO_SHIROU_FEATURE_STARTED_AT_MS=null`を継続する。
