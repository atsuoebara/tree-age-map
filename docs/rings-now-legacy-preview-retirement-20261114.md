# Rings Now 旧実FIT試作ページの公開読取停止（2026-11-14）

## 何を止めるか
むせ監査PR #116で、旧 `previews/ima-wo-shirou-fit-local-file-draft-20261113.html` が本番GitHub Pages上でHTTP 200により公開されていると確認された。本人が新しい実FIT試験を承認していないため、**旧ページの実FITファイル選択・JavaScript解析能力を撤去**する。

このPRは、旧URLを404にする**ファイル削除ではない**。過去リンクへ訪れた人に説明する目的で、同じHTMLファイルを**スクリプト・フォーム・file inputなしの無害化案内ページ（tombstone）**に置換する。静的CSPに`script-src 'none'`と`connect-src 'none'`、`form-action 'none'`を付ける。noindexやCSPはアクセス認証ではない。旧URLそのものは配信され続ける。

## 安全上の理由
- 本番公開の実FIT入力試作ページを放置せず、**新しい実FIT公開・利用承認とは切り離して**入口を無効にする。
- 既存のiPhone合成専用ページは変更しない。SHA-256一致の合成294byteだけを許す既存動作を保持。
- `index.html`、`sw.js`、Supabase、既存カレンダー、ラン取り込み、FIT SDK、FIT解析エンジンは変更しない。Rings Now入口は`false`で、開始時刻は`null`のまま。
- 旧公開HTMLのテストは「以前の読み取り画面の動的仕様」を保持せず、**現時点で読み取り不能であること**をアサートする。既存のFIT SDK本体、PR #114/115の独立ゲート/UIは合成FITテストで引き続き検証する。
- ローカルPC専用の既存サーバー／バンドラは古いHTMLを参照するため、そのHTMLも無害化される。PC向けPR #109はHOLD。旧ローカルUIの実FIT再現テストは廃止し、同じ機能を誤って再公開することを避ける。
- 履歴の旧コードはGitHubのコミット履歴に残るが、そこに個人FITファイルは含まない。**以前アクセスしていたタブやブラウザのHTTPキャッシュ、配信CDN反映遅延は、このPRだけでは即時に無効化できない**。実際の公開HTMLのレスポンス本文確認はマージ後の独立本番監査で必要。

## テスト更新
- 既存FIT SDKテストはパーサーの合成データ検証を維持。旧ページ固有の文言・フォーム前提だけ撤去。
- iPhone File API試験は現在動いている合成専用ページへ移す。
- 旧ローカルサーバーと旧Chromeページのテストは「旧ページからSDK/実FITを呼べない」という退役後の契約に変更。
- 旧FIT scope checkerは今回修正するテスト＋文書＋CIの個別ファイル名だけを追加し、`index.html`、`sw.js`、Supabase等は引き続き拒否。
- 専用CIで新旧テストの回帰を行う。

## むせ独立監査依頼
1. 旧URLの静的HTMLにfile input、script、form、動的import、FIT SDKへのリンク、通信/保存経路が**皆無**か。
2. 修正対象が旧ページ＋関連する回帰テスト／scope checker＋文書／CIのみか。旧URLは404ではなく説明ページとして残ることが正しく説明されているか。
3. 合成FIT用iPhoneテスト・新UIコントローラ・既存カレンダー・SW・DBが無変更か。
4. 既存CI（本PRで起動するもの）と新CIが成功したか。歴史的なPC実FITページの動作テストを削除したことで重要なデコーダ回帰が欠落していないか。
5. マージ前の現行本番が旧読取ページのままであることを明確にし、本人承認があってマージした**後**にページ本文を再確認すること。

**監査のみ／本人明示承認まではマージ禁止**。実FITの新画面公開、本番Rings Now解禁、実FIT使用はこのPRに含まれない。
