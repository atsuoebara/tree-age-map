# PR #128：Rings Now 公開差し替え・停止と古いタブの隔離リプレイ（2026-11-14）

## 目的
PR #127の旧タブ・撤去判断ゲートを、架空の2世代（v1/v2）・複数タブによる時系列シミュレーションで再検証する。実FIT・個人識別子・GPS・心拍・公開ページ・外部通信を一切使わない。旧タブが勝手に新しい公開状態を認識するという誤った仮定を排除する。

## 実装範囲
新規4ファイル（隔離シミュレータ、テスト、この文書、専用CI）。本番HTML、既存Safari試験ページ、SW、DB、カレンダー、FITエンジン、feature flagは無変更。

replaySyntheticTabScenario は事前指定された架空イベント open / publish / withdraw / receiveVerifiedSignal / hide / pagehide / resume / close を実際のブラウザではなくメモリ内の状態として順に実行する。PR #127 の evaluateSyntheticTabRetirement を呼び、各タブの見えているバージョンと、シミュレータだけが知る現在の公開状態を分けて記録する。

### テストする重要事例
1. v1の旧タブを開いたままv2公開 → 古いタブは最新公開バージョンを自動で知ることができない。
2. 旧タブが一度v1シグナルを確認し、その後サーバー側でwithdraw → 新しいシグナルを受信しない古いタブは撤去を認識できない。シミュレータは observationGap=true を記録し、remotelyRevokedGuaranteed=falseを維持する。
3. 停止シグナルを新たに受信した場合、その模擬タブのローカル判定は blocked となるが、他の開いたタブ全体を強制停止できる保証はない。
4. 新旧タブの状態は独立。新しいv2タブが動いても旧v1タブを自動で無効化したことにはならない。
5. pagehide／非表示から復帰しても、その模擬タブの失効は解除されない。
6. 不正イベント、シグナルなし、未知状態ではfail-closed。

## 明示的に未解決のこと
- 実際の停止シグナルの取得・署名・鮮度・配信・通信方法は未設計。シミュレータのreceiveVerifiedSignalは外から「検証済み」と仮定したイベントで、検証技術ではない。
- 古いタブがオンラインでない場合や、キャッシュしたJSを実行し続ける場合、ページ差し替え・撤去だけで実際に停止させられる保証はない。
- GitHub Pages/CDN/Safari HTTPキャッシュ、SW・実機のネットワークキャプチャや緊急停止の実地演習は未実施。
- 通信を一切禁止する方針と、停止状況をリアルタイム取得する方式にはトレードオフがある。採用方式は未決定。
- テストでの requires_manual_review は実FIT利用や本番ONの許可ではない。14条件の証跡も未認定。
