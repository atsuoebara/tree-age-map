# Rings Now（NOW × KNOW）：iPhone先行・FITの端末内読取検証（2026-11-14）

## 本人による名称と端末方針の変更
- 正式な表示名は **Rings Now（リングスナウ）**。本人の意図は「今」の **NOW** と「知る」の **KNOW** の二重の意味。旧「今を知ろう」のUI名は今後置換するが、内部モジュール名を無断で一括リネームしない。
- 本人は「何故PC?」と指摘。PC必須の導線は採用しない。**既存カレンダー → 本人の個別ガチラン選択 → iPhone内のFIT確認**が目標。PCは任意の補助。
- PR #109はPC向け条件付き手順のDraftで**HOLD**。本PRは #109 をマージ前提にしない。名称変更の文書PR #110は別途独立監査待ち。

## 現時点の技術的確認と未検証
- 既存隔離プレビューは `<input type="file" accept=".fit,application/octet-stream">` と `file.arrayBuffer()` を利用。Safari iOSは一般に標準のFile/Blob読み込みに対応する（参考: https://developer.mozilla.org/en-US/docs/Web/API/Blob/arrayBuffer）。PC固有APIは使っていない。
- **これはコード調査と静的テストであり、iPhone実機でFITを読み込めた証明ではない。** iOSのファイルピッカーでGarmin由来FITを選択可能か、16MB以内か、処理時間・メモリ・ファイル書式を実機で検証する必要がある。
- 既存プレビューHTMLは端末内でFITを読み取るが、JavaScriptモジュールを外部配信する必要がある。**現行PC localhostのプレビューURLはiPhoneから開けない**。iPhone専用の安全な配信経路（HTTPS、認証・制限・更新挙動・サービスワーカー影響・アクセスログ・画面表示）を別途検証する。公開テストページで本人の実FITを読み込ませない。端末内読取とHTML/JSの通信・配信は異なる論点で、プレビューの安全性を検証せずに自動公開しない。
- ユーザーの実FIT・位置情報・心拍・ログをGitHub/チャット/サーバーへ送らず、データベース書込みもしない。ネットワーク禁止、ファイル選択の本人操作、解析結果の非永続化を維持。
- 2026-11-03ぐんまマラソンは本番8日期限を超過。隔離デコーダ検証のみ可能という区別を維持。

## 独立監査後の段階的なiPhone実機確認（まだ許可していない）
1. **まず架空・合成FITのみ**を使ったiPhone実機テストのための閲覧方法を別途設計・監査。無断で公開ページを増やさない。
2. iPhoneの「ファイル」からFIT1件選択、選び直し・ログアウト・表示中断・16MB制限・端末の動作を実機確認。別タブでネットワーク送信しないという推測ではなく、検査可能な通信制限・コードの経路を確認する。
3. 実FITの使用は別途むせ独立監査とAtsuoの明示承認を得てから。実データは外部にアップロードしない。
4. 品質候補は `candidate_unverified`、`analysisAllowed:false`。信号やトイレで一律除外せず、停止込みの時計経過時間で扱い、欠損は補完せず、正確性の注意書きを表示する。旧方針は復活させない。
5. 本番の機能有効化、色、英語UI、適用開始時刻、保存済みカレンダー行とのFITの同一性は別の審査対象。現在のOFFゲートを変更しない。

## テストの意味と限界
`node --test tests/rings-now-iphone-file-readiness.test.cjs` はFile APIの利用形態・非送信・OFFを固定する静的監査ゲート。**iOS Safariの実行を自動テストしたものではない**。ブラウザ互換性、iPhoneでの開封可否、通信挙動や実FIT品質は判定不能。
