# B-1 匿名公開 T1〜T9 合成試験仕様 v0.1
作成日: 2026-11-01
状態: **監査前の試験設計。閾値未決定。本番適用・同意受付・数値公開は禁止。**

## 目的と前提
既存の `docs/b1-public-anonymity-policy-review-v01-20261030.md` および `docs/b1-public-server-delivery-year-close-v02-20261030.md` を引き継ぐ。
公開候補は国×締め済み暦年の丸めた合計距離だけ。公開前の承認、失効、再公開禁止、都度認可は既存設計のまま維持する。
**合成データのみ**を使う。実ユーザーの詳細距離・GPS・同意状態は試験記録やGitHubへ持ち込まない。

## 比較する候補（採用値ではない）
- 最低ユニーク寄与者数: 5, 10, 20, 30, 50, 100
- 最大寄与者の合計距離比: 10%, 20%, 30%, 40%（超えたら抑制する候補）
- 上位2・上位3人の合計寄与比: 30%, 40%, 50%, 60%（超えたら抑制する候補）
- 距離丸め刻み: 100, 500, 1000, 5000km。四捨五入と切り捨てを別試験し、境界近傍を重点検査する
- スナップショット: 同一国×年は原則一度だけ公開。訂正・撤回後は停止が先で、旧版との差分評価なしの再公開を許さない
候補組合せのうちどれかに合格したというだけで採用しない。他の公開統計や既知情報を使う攻撃に耐える必要がある。

## 自動試験の出力
- 各候補ごとに pass/fail/要人手審査を記録する
- 攻撃者が見られる公開値のみを入力とし、推定した寄与の範囲幅、真値の包含、前後差分の有無を記録する
- 「一意復元不能」だけで合格にしない。極端に狭い推定区間なら不合格・人手審査へ
- 失敗・未検証・閾値未決定は**公開不可**に倒す
- 実公開までに、差分を悪用できる既存のToday/公開統計/APIとの横断検証を実施
- 実ユーザーデータを使用した評価が必要になった場合は、アクセス権・監査・保持期間を別途承認する。GitHubやログへ個人値を出さない

## むせ独立監査への依頼
1. T1〜T9に漏れている攻撃（シビル攻撃、既知寄与、繰り返し照会、複数セル差分、既存統計）を列挙
2. 最低人数、上位寄与支配、丸め幅の候補が妥当な探索範囲か検証
3. 推定区間幅の受入基準と公開価値の両立条件を提案
4. 年締めの帰属・2027-04-01T00:00:00Z候補を、実データ定義との整合検証後に確定できるか評価
5. 公開不能の場合に数値なし表示を選択する停止条件を確認
