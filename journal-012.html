Runner's Rings Version 1.0をリリースしました ─ 「走った人生を残す」地図へ

2026.09.23 ・ Version 1.0

今日、Runner's Rings Version 1.0を正式にリリースしました。

Runner's Ringsは、ランニングの記録をただ数字として残すのではなく、自分が走ってきた道や地域を地図に積み重ねていくために作ったサービスです。

走った記録ではなく、走った人生を残す。

この言葉を中心に、走った道が増えるほど、自分だけの地図が育っていくものを目指して開発してきました。

Version 1.0でできること

Runner's Ringsでは、GPS付きのランニングデータを取り込み、これまで走ってきた道を一つの地図に重ねて見ることができます。

主なデータ取込方法

・Strava

・COROS

・Intervals.icu

・Garmin Connect IQ

・FIT / GPX / TCX / ZIP ファイル

地図は「面」と「コース」の両方から見ることができ、ALL・年・月で走った軌跡を振り返ることもできます。

さらに、走った都道府県や市町村などを可視化する地域走破、走った地域を記念として残す制覇カードなど、距離やタイムだけでは見えないランニングの積み重ねも形にしています。

過去のランも、これからのランも

Runner's Ringsで大切にしたかったのは、「今日走ったか」だけではありません。

昔走った道、旅先で走った道、いつもの近所の道。何年も前のランでも、その人が実際に走った時間であることに変わりはありません。

過去のデータを取り込めば、それまでのランニング人生も地図の上に戻ってきます。

そして、これから走る一本一本が、その地図に新しい線や地域を加えていきます。

日本から、世界のランナーへ

Version 1.0では、日本国内だけでなく海外のランニングも地図に残せるよう、国や地域の表示にも対応を広げてきました。

まだ改善したいところ、追加したい機能はたくさんあります。Version 1.0は完成というより、Runner's Ringsが正式に走り始めるスタートラインです。

ここから始まります

速い人だけのサービスではありません。たくさん走る人だけのサービスでもありません。

1kmでも、旅先の一本でも、毎日のいつもの道でも。その人が走った場所には、その人だけの物語があります。

Map the life you run.
あなたが走った人生を、地図に。

Runner's Ringsは今日、Version 1.0になりました。ここから、もっと多くのランナーの「走った人生」が地図に残っていくことを楽しみにしています。

Runner's Rings Version 1.0 Is Here — A Map for the Life You Run

2026.09.23 ・ Version 1.0

Today, Runner's Rings Version 1.0 is officially released.

Runner's Rings was built to preserve more than running statistics. It brings together the roads and regions you have actually run and lets them grow into a map of your own running history.

Map the life you run.

That idea has guided the project from the beginning: the more you run, the more your own map grows.

What Version 1.0 can do

Runner's Rings imports GPS-based running data and brings your past routes together on one map.

Main ways to import running data

・Strava

・COROS

・Intervals.icu

・Garmin Connect IQ

・FIT / GPX / TCX / ZIP files

You can explore your history through both area and route views, and look back across ALL-time, yearly, and monthly periods.

Region Conquest turns the places you have run into visible progress, while Conquest Cards preserve milestones from the regions in your own running history.

Your old runs matter, too

Runner's Rings is not only about what you ran today.

An old route, a run while traveling, or the roads around home all belong to the same story. Even a run from years ago is still time you spent running.

Import your past data, and those years of running can become part of your map again.

Every new run then adds another road, another region, and another layer to that history.

From Japan to runners around the world

Version 1.0 has also expanded beyond Japan, with support for displaying running activity across countries and regions overseas.

There is still plenty to improve and build. Version 1.0 is not the finish line. It is the starting line for Runner's Rings as a released service.

This is where it begins

Runner's Rings is not only for fast runners, and it is not only for people who run huge distances.

One kilometer, one run on a trip, or the same familiar road every day — every place you run becomes part of your own story.

Map the life you run.
Turn the life you run into a map.

Runner's Rings is now Version 1.0. I am looking forward to seeing more runners build maps from the lives they run.
