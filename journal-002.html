StravaとIntervals.icu、Runner's Ringsではどう使い分ける？

2026.09.14 / Runner's Rings 開発ノート

Runner's Ringsには複数のデータ取り込み方法があります。その中でもよく聞かれるのが、StravaとIntervals.icuのどちらを使えばいいのか、という質問です。

結論から言うと、Runner's RingsではStravaかIntervals.icuのどちらか一方を主な取り込み元にするのがおすすめです。

なぜ両方をつながない方がいいのか

同じランがStravaとIntervals.icuの両方に存在する場合、同じデータが二重に入る可能性があります。Runner's Ringsでは日付・距離・開始時刻・ルートなどを使って重複判定をしていますが、最初から取り込み元を1つに決めておく方が管理はシンプルです。

トレーニング管理の中心がStravaならStrava経由。Intervals.icuを日常的に使っているならIntervals.icu経由。Runner's Ringsは、そのデータを「走った人生の地図」に変える役割です。

役割が違うからこそ組み合わせる

StravaやIntervals.icuは、トレーニングやアクティビティ管理に強いサービスです。一方、Runner's Ringsは「どこを走ってきたか」「どの地域まで広がったか」を地図で見ることを中心にしています。

同じランニングデータでも、見る目的が違えば価値も変わります。

迷ったら、普段いちばん使っている方から

Runner's Ringsのために新しい運用を無理に増やす必要はありません。今まで使ってきたサービスを入口にして、そこからRunner's Ringsへ取り込む。これが一番自然です。

Strava or Intervals.icu — Which Should You Use with Runner's Rings?

2026.09.14 / Runner's Rings Development Note

Runner's Rings supports several import methods. One common question is whether Strava or Intervals.icu should be used.

In most cases, it is best to choose either Strava or Intervals.icu as your main source.

Why not connect both?

If the same run exists in both services, duplicate data may be imported. Runner's Rings includes duplicate detection using date, distance, start time, and route information, but using one main source keeps things simpler.

If Strava is your main training hub, use Strava. If you already live in Intervals.icu, use Intervals.icu. Runner's Rings turns that activity data into a map of your running life.

Different tools, different roles

Strava and Intervals.icu are strong at activity and training management. Runner's Rings focuses on where you have run and how your map has expanded.
