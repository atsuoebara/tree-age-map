集計ルール：同じ人が同じ日に同じ地域を複数回走っても人数は1カウントです。別の地域を走った場合は、それぞれの地域で1カウントします。距離はその地域内を走った分を合算します。Rings Todayは参加ON/OFFに関係なく自動集計しますが、個人名・ユーザーID・走行ルートは公開しません。

Counting rule: one person counts once per region per day even if they run there multiple times. Visiting another region counts once there too. Distance is summed within each region. Rings Today is aggregated automatically regardless of participation settings, while names, user IDs and personal routes are never published.
